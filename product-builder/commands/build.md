---
description: 從想法到能點的產品——引導走完 PRD → 優先級 → 規格 → 畫面的生產流程
argument-hint: "<產品想法或要做的功能>"
---

引導使用者把想法變成能點的產品，依序走：

1. 想法還模糊 → 先用 prd-write skill 寫產品規格（問題、Goals/Non-Goals、成功指標）：$ARGUMENTS
2. 功能太多 → 用 roadmap-prioritize skill 排出 Now / Next / Later
3. 決定視覺方向 → design-system skill 建 tokens；要參考風格可用 design-material-3
4. 畫面定義 → design-spec skill 寫畫面規格
5. 產出 → ui-generate skill 生成能在瀏覽器點的前端，或 figma-design skill 生成 Figma 設計稿
6. 加分 → motion-design skill 調動效手感、api-connect skill 串真資料

每一步的輸入不足就先問使用者，不腦補任何產品內容。使用者可以從任何一步進場。
