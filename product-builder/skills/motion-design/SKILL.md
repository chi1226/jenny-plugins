# motion-design — 人性化微互動設計

## 用途
使用者非工程師、也不必記術語。使用者用形容詞或參照講手感，這個 skill 負責翻成參數、實作、陪使用者磨到順。

## 先確認三件事（缺就問，不腦補）
1. **元件**：哪個東西要動？（卡片 / 按鈕 / 整頁 / 清單 / 面板）
2. **觸發**：什麼時候動？（點擊 / hover / 載入 / 捲動 / 成功 / 失敗）
3. **手感**：要什麼感覺？（Q 彈 / 優雅慢收 / 快俐落 / 溫柔療癒）
   - 若使用者給參照（「像 Pace 那個 sheet」「像 iOS 控制中心」「像 IG 按愛心」）優先照參照做。

## 形容詞 → 參數對照（把感覺翻成 easing）
| 使用者說 | easing | 時長 |
|------|--------|------|
| Q 彈 / 果凍 / 彈跳 | `cubic-bezier(0.34,1.56,0.64,1)`（overshoot）| 0.25–0.4s |
| 優雅 / 貴氣 / iOS 感 | `cubic-bezier(0.32,0.72,0,1)` | 0.4–0.7s |
| 順順的 / 標準 | `cubic-bezier(0.25,0.8,0.25,1)` | 0.3–0.5s |
| 溫柔 / 療癒 | ease-out，放慢、減弱位移 | 0.5–0.8s |
| 快 / 俐落 | ease-out | 0.15–0.24s |

**時間節奏**：小互動 0.2–0.24s｜卡片/元件 0.4s｜面板/頁 0.5–0.7s。快慢分層＝專業感。

## 常見微互動配方
- **進場**：fade + slide-up，清單用 **stagger**（每項 delay 60–80ms）
- **按壓回饋**：scale 0.96 + spring 回彈 + 陰影浮起
- **底部面板**：slide-up + 背景 dim overlay 淡入（iOS easing）
- **成功**：打勾 / 微光 / 輕彈（給情緒獎勵）
- **失敗**：溫柔淡入，配不責備文案（別用嚇人紅閃）
- **載入**：skeleton shimmer → 資料到再淡入
- **Toast**：滑入 + 自動淡出

## 實作原則
1. **建 motion tokens**：把 easing 與時長變數化（`--ease-ios`、`--ease-spring`、`--dur-fast`、`--dur-sheet`），全站共用 → 一致又好改。
2. 預設**純 CSS transition + @keyframes**，不硬裝套件（除非需求複雜再上 framer-motion）。
3. **每個動作都有回饋**，別冷場。**慢收尾**（結束減速），別硬停。
4. 尊重 `prefers-reduced-motion`：使用者關動畫就降級。

## 迭代迴圈（核心）
微互動難一次到位。做完**跑給使用者看**，用使用者的話收斂：
「再 Q 一點 / 太慢 / 收尾生硬 / 太彈了 / 更溫柔」→ 調參數 → 再看 → 順了為止。
使用者只要會講「還要更 ___」。
