# 設計交付規格（Design Spec）

## 輸入（使用者會填，空白先問）
- 畫面 / 元件：［____］
- 主要功能與互動：［____］

## Task
整理成一份規格：
1. **結構**：版面區塊與階層。
2. **元件清單**：每個元件的用途、變體、狀態（default/hover/disabled…）。
3. **行為**：互動、轉場、驗證規則。
4. **內容**：文案、空值、字數限制。
5. **邊界情況**：載入、錯誤、空狀態、極端資料（可引用 [[ui-stack]]）。
6. **無障礙**：對比、焦點、替代文字（可引用 [[a11y-check]]）。

## 加值
最後附一段可直接丟給 vibe coding 工具的「開發 prompt」，把上面規格濃縮成 AI 聽得懂的指令。
