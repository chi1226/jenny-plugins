## Context

（欄位 使用者會填。空白先問，不要腦補。）

## Task
為這個頁面生成完整的 UI Stack，包含：
1. **Blank State**：什麼情況出現，使用者應該看到什麼，CTA 是什麼
2. **Loading State**：建議使用哪種載入方式，原因是什麼
3. **Partial State**：哪些部分可能先出現，哪些後出現
4. **Error State**：列出所有可能的錯誤情境，以及各自的設計建議
5. **Ideal State**：除了正常顯示，有什麼 Delight 機會？
