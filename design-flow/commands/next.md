使用 design-router skill 的流程來導航：

1. 了解使用者目前的專案、手上有什麼素材、卡在哪：$ARGUMENTS
2. 判斷他們落在雙鑽石的哪一格（探索/定義/發展/交付）
3. 建議下一步該用這個 plugin 裡的哪 1–2 個 skill，以及需要先準備什麼輸入
4. 若缺專案脈絡，建議先用 project-brief skill 建立專案簡報

只指路、點出缺的輸入，不代替使用者做決定。
