# 生成完整使用情境分析

## Context
我在設計 ［產品名稱］，核心功能是 ［描述］，目標使用者是 ［描述］。

（欄位 使用者會填。空白先問，不要腦補。）

## Task
為這個產品生成 3 個不同的使用情境，每個情境包含：
1. **Who**：使用者此刻的狀態和動機
2. **Task**：表面任務 vs 真正目標
3. **Environment**：物理 / 社交 / 技術環境
4. **Time & Emotion**：時間壓力與情緒狀態

最後列出這三個情境中，最容易被設計師忽略的設計需求。
