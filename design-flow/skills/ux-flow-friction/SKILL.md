# 找出 UX Flow 的摩擦點

## Context
我正在設計 ［產品名稱］，目標使用者是 ［描述］。以下是使用者完成 ［任務名稱］ 的 UX Flow：

（產品、使用者、任務、flow 內容 使用者會填。若空白，先請使用者補齊，不要腦補任何產品。）

## Task
分析這個 UX Flow，找出：
1. 最可能造成使用者放棄的 3 個節點
2. 每個節點目前的設計對策
3. 建議的改進方向（各 1–2 句）

## Output Format
條列式：節點名稱 / 摩擦來源 / 目前對策 / 建議方向。最後附上這個流程最大的設計風險是什麼。
