# 從洞察 + Job Story 生成 PS 候選

## Context
根據以下對 ＿＿＿＿＿ 的洞察和 Job Story，請產出 Problem Statement 候選：

（洞察與 Job Story 內容 使用者會填。若空白，先請使用者貼上，不要腦補。）

## Task
產出 3 個 PS 候選，採用「[使用者] 在 [情境] 下，遇到 [障礙]，因為 [根因]，導致他無法完成 [任務目標]」句式。三個候選分別強調：
- 心理層障礙
- 情境觸發點
- 任務目標的內在狀態

## Output Format
每個 PS 附：
- 四個欄位拆解（使用者 / 情境 / 障礙 / 根因＋任務目標）
- 對應到 M1/M2 的哪部分
- 開啟的 3 個方向
- 排除的 3 個方向
