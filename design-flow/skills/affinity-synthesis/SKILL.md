# 研究洞察歸納（Affinity Synthesis）

## 輸入（使用者會填，空白先問）
- 研究主題：［____］
- 原始資料（訪談逐字稿 / 觀察筆記 / 開放題回覆）：［貼入］

## Task
1. 把資料拆成一則則「觀察點」（原話或行為，不加詮釋）。
2. 相似觀察點分群（affinity），每群下一個標題。
3. 每群萃取 1 個 Key Finding（一句話，含「因為/所以」的張力）。
4. 標出最反直覺、最值得深挖的 2–3 個洞察。

## Output Format
分群清單（群標題 + 底下觀察點）→ 每群 Key Finding → 重點洞察 Top 3。最後標明哪些 finding 證據不足、需要再驗證。

## 銜接
產出的 Key Finding 可直接餵給 [[jtbd-write]]、[[job-story]]、[[problem-statement]]。
