# 專案簡報（Project Brief）

## 用途
每個 skill 都要重填產品/使用者很煩。這個讓 使用者 一次填好一個專案的固定脈絡，存成檔案；之後使用者說「用我的 ○○ 專案」，其他 skill 就從這裡取用，不必再問、也不由 AI 腦補。

## 建立流程
1. 問使用者 專案代號（檔名用），例：sanpai、pace。
2. 請使用者填以下欄位（缺的先問，不腦補）：
   - 產品名稱：
   - 一句話定位：
   - 目標使用者：
   - 核心需求 / 痛點：
   - 核心功能：
   - 商業目標（如有）：
   - 視覺定位（如有）：
   - 現階段（雙鑽石哪一格）：
3. 存到 `~/Desktop/chi-agent/.claude/project-briefs/<代號>.md`。

## 引用規則
- 使用者 說「用我的 <代號> 專案」→ 讀該檔，把欄位帶入正在跑的 skill。
- 檔案沒有的欄位 → 問使用者，不自行填。
- 這是唯一允許「預帶產品脈絡」的來源；skill 本身仍一律留空。
