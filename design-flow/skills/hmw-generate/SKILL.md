# 生成 HMW 候選

## Context
以下是 ＿＿＿＿＿ 的 Problem Statement 候選，請生成 HMW 候選作為設計探索入口：

（PS 內容 使用者會填。若空白，先請使用者貼上，不要腦補。）

## Task
生成 8 個 HMW，符合：預設問題有解 + 不預設唯一解法 + 範圍剛好。從 4 個切入角度各 1–2 個：
- **痛點切入**：HMW 消除 X？
- **反面切入**：HMW 把 X 變成 Y 的機會？
- **情境切入**：HMW 在 X 情境下，達到 Y？
- **互補機制切入**：用 X 達到 Y，但不依賴 Z？

## Output Format
切入角度標註 + 對應 PS 的哪個元素 + 開啟的 3–5 個方向示例。
