# 資訊架構與 User Flow 設計

## 輸入（使用者會填，空白先問，或引用 [[project-brief]]）
- 產品 / 功能：［____］
- 目標使用者與主要任務：［____］
- 已知的畫面或內容（可選）：［____］

## Task
1. **資訊架構**：列出主要區塊/頁面與階層關係。
2. **核心 User Flow**：畫出使用者完成主要任務的步驟（起點→決策點→終點），用文字流程圖表示。
3. **分支與例外**：成功路徑外，標出失敗路徑、空狀態、返回點。
4. 指出流程中最關鍵的決策節點，以及可簡化的地方。

## 銜接
產出的 flow 可交給 [[ux-flow-friction]] 找摩擦、[[ui-stack]] 補每頁狀態。
