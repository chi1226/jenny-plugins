# 設計發想（Ideation）

## 輸入（使用者會填，空白先問）
- 要發想的 HMW / 題目：［____］
- 限制或已知條件（可選）：［____］

## Task
產出多元解法，刻意拉開差異：
1. **Crazy 8s**：8 個快速點子，從安全到極端。
2. **SCAMPER 掃一輪**：替代/結合/調整/放大/挪用/消除/重排，各挑有料的。
3. **反直覺 2 個**：如果反過來做會怎樣？
4. 標出：最安全、最大膽、最值得做原型驗證的各 1 個。

## 原則
- 發散階段不批判、要量也要極端。
- 不預設科技解法，先講「做什麼」不講「用什麼技術」。
- 銜接 [[ui-stack]] / prototype 做收斂。
