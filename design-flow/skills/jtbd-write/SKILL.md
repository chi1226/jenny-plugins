# 撰寫 JTBD

## 輸入（使用者會填，空白先問）
- 主題：［主題］
- Key Finding：［貼入一個 Key Finding］

## Task
根據研究發現，生成 3 個不同層次的 JTBD 描述。

格式參考：
「當 ［情境］ 發生時，使用者希望能夠 ［完成什麼人生任務］，即使目前的解法 ［有什麼不足］」

注意：人生任務要聚焦在「身份感」或「長期目標」，而不是 App 功能。
