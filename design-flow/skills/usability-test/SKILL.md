# 易用性測試（Usability Test）

## 輸入（使用者會填，空白先問）
- 模式：［寫腳本 / 分析結果］
- 產品與要測的流程：［____］
- 若分析結果：貼入觀察紀錄：［____］

## Task A — 寫腳本
1. 測試目標（想驗證的假設）。
2. 3–5 個任務情境（不暗示操作，讓受測者自然做）。
3. 每任務的成功標準與觀察重點。
4. 前導問句 + 事後訪談題。

## Task B — 分析結果
1. 把觀察歸類成問題，標嚴重度（阻斷/困擾/小瑕疵）。
2. 每個問題附可能原因 + 修正方向。
3. 排優先級（影響 × 頻率）。

## 原則
- 任務用情境包裝，不直接說「請點某按鈕」。
- 分析只根據觀察到的，不腦補使用者想法。
