# 分析使用者心智模型缺口

## Context
我正在設計 ［產品名稱］，目標使用者是 ［描述］。他們過去主要使用的類似產品是 ［競品或參照產品］。

（欄位 使用者會填。空白先問，不要腦補。）

## Task
基於他們的使用經驗，分析：
1. 他們對這類產品可能有什麼預期（操作方式、介面結構、回饋機制）
2. 我的設計 ［描述核心設計決策］ 中，哪些地方可能違反這些預期
3. 對每個落差，建議用「符合、修正、建立新模型」哪種策略應對
