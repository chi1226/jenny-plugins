# 人物誌建立（Persona）

## 輸入（使用者會填，空白先問）
- 研究發現 / Key Findings：［貼入，可引用 [[affinity-synthesis]] 產出］

## Task
收斂成 1–2 個 persona，每個含：
- 一句話身份 + 代表情境
- 目標與動機（表面 vs 深層）
- 主要痛點與挫折
- 現在怎麼解決（既有做法/替代品）
- 行為特徵與使用情境
- 最能打動他的價值主張

## 原則
- 從研究長出來，不憑空捏；沒證據的欄位標「假設」。
- 要有張力與取捨，不要「什麼都想要」的萬用人。
- 銜接 [[job-story]] / [[jtbd-write]] / [[context-scenario]]。
