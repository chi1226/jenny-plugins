# 競品設計探索

## Context
我正在設計 ［產品名稱］，目標使用者是 ［描述］，核心需求是 ［描述］。

（欄位 使用者會填。若空白，先請使用者補齊，不要腦補任何產品。）

## Task
從 Mobbin 找 5 個 ［同類別］ App 的首頁案例，分析每個的：
- **視覺層級策略**——最高視覺權重落在哪個元素？
- **主要 CTA 的位置與大小**
- **資訊密度**——首頁同時呈現幾個主要資訊區塊？

## Output Format
整理成對照表，最後推薦最符合 ［產品名稱］ 設計方向的案例，並說明理由。
