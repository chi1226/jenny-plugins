# 設計流程領航（Design Router）

## 用途
使用者手上有 30+ 個設計/研究/商業 skill，容易忘記何時用哪個。這個 skill 幫使用者定位、指路。

## 流程
1. 問使用者：現在的專案 + 手上有什麼、卡在哪。
2. 判斷使用者落在雙鑽石哪一格：
   - 探索（發散1）→ [[interview-guide]] [[interview-review]] [[affinity-synthesis]] [[context-scenario]]
   - 定義（收斂1）→ [[persona-build]] [[jtbd-write]] [[jtbd-to-hmw]] [[job-story]] [[job-story-review]] [[problem-statement]] [[ps-critique]] [[hmw-generate]] [[hmw-review]]
   - 發展（發散2）→ [[ideation]] [[competitor-scan]] [[ia-userflow]] [[ui-stack]]
   - 交付（收斂2）→ [[usability-test]] [[design-critique]] [[design-spec]] [[a11y-check]] [[error-message]] [[taste-train]] [[ux-flow-friction]] [[mental-model-gap]]
   - 商業（貫穿）→ [[mvp-plan]] [[bmc-canvas]] [[product-metrics]] [[product-moat]] [[pricing-growth]]
   - 產品定義（PM 線，定義→發展之間）→ [[prd-write]] [[roadmap-prioritize]]
   - 整體流程 → [[double-diamond]]；落地 → [[api-connect]]；作品集 → [[case-study]]；面試 → [[mock-interview]]
3. 給使用者：你在這格 → 建議下一步用 X skill → 它需要你先備好 Y。
4. 若脈絡缺，提醒使用者先建/引用 [[project-brief]]。

## 原則
只指路、點出缺的輸入，不代使用者做決定。一次建議 1–2 個下一步，不倒整張地圖。
