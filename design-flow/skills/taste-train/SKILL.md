# 幫助鍛鍊品味

## Context
我正在設計 ［產品名稱］，視覺定位是 ［描述，例：穩定、值得信賴］。
目前已決定：主色為 ［色彩］、圓角使用 ［圓角大小］、字型為 ［字型］。

（欄位 使用者會填。若空白，先請使用者補齊，不要腦補任何產品或決策。）

## Task
根據以上視覺定位，評估這三個決策是否一致：
- **色彩**：所選主色是否符合視覺定位的情緒？
- **圓角**：所選圓角是否適合使用情境？
- **字型**：所選字型是否強化或削弱品牌語氣？

## Output Format
針對每個決策給出「符合 / 部分符合 / 不符合」，並說明理由，最後提出一個需要調整的建議。
