# job-hunt-designer

設計師求職包 —— 作品集敘事 + 模擬面試。

*Job-hunting toolkit for designers: case-study storytelling, reusable project briefs, and tough mock interviews. Skills are written in Traditional Chinese.*

由 [Jenny Liu](https://jenny-liu.framer.website/) 打造。3 個 skill 覆蓋求職準備的核心工作：把專案講成故事、把脈絡存檔重用、把面試練到穩。

## 安裝

```bash
claude plugin marketplace add chi1226/jenny-plugins
claude plugin install job-hunt-designer@jenny-plugins
```

## 使用方式

```
/job-hunt-designer:prep 我要投 Product Designer，作品集還沒整理
```

## Skill 一覽

| Skill | 用途 |
|---|---|
| project-brief | 一個專案填一次脈絡（產品、使用者、目標），之後其他 skill 直接引用，不用重講 |
| case-study | 把專案的設計流程包成求職 case study：背景 → 問題 → 過程 → 決策 → 成果 → 反思 |
| mock-interview | 針對指定職位出題、逼問、給回饋，支援上機／口試演練 |

## 設計原則

- **不腦補**：不假造使用者的經歷、數據或作品內容，缺什麼先問。
- **決策優先**：case study 的重點是「為什麼這樣選」，不是流程流水帳。
- **面試要真練**：mock-interview 會追問到底，不是餵標準答案。
