了解使用者的求職狀態並指路：$ARGUMENTS

1. 還沒整理作品 → 用 project-brief skill 先把專案脈絡建檔，再用 case-study skill 包成求職敘事
2. 作品集有了、要面試 → 用 mock-interview skill 針對目標職位出題、追問、給回饋
3. 不確定缺什麼 → 問清楚目標職位的 JD，對照現有作品找缺口

資訊不足先問，不腦補使用者的經歷或作品。
